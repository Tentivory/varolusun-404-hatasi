# Varoluşun 404 Hatası

> Evren bir REST API değildir ama biz yine de GET atıyoruz.

Bu depo, insanlığın en eski sorusunu (“Neden varız?”) modern yazılım mühendisliğinin en kısa cevabıyla (“404”) birleştiren **kurumsal düzeyde saçma** bir araçtır.

## Neden bu proje var?

Çünkü:

1. Var.
2. Yok da olabilirdi.
3. 404 dönmesi daha dürüst.

## Kurulum

```bash
python3 varolus.py
```

Başka bir şey kurmanıza gerek yok. Zaten evren de sizi kurmamış.

## Kullanım senaryoları

- Gece 03:17’de anlam aramak
- Stand-up toplantısında “blocker” olarak göstermek
- Felsefe dersine ödev diye göndermek (not: önerilmez, önerilir)
- Copilot ile tartışmak (Copilot genelde 200 döner, bu repo 404)

## Mimari

```
[Kullanıcı] --var mıyım?--> [varolus.py] --GET /anlam--> [Evren]
                                              |
                                              +-- 404 Not Found
                                              +-- 418 I'm a teapot
                                              +-- 451 Unavailable For Legal Reasons (nadiren, şaka)
```

## Katkıda bulunma

Pull request açabilirsiniz. Merge edilip edilmeyeceği evrenin keyfine kalmıştır.
Issue açabilirsiniz. Issue’lar da 404 olabilir.

## Sık sorulan sorular

**Bu çalışıyor mu?**  
Evet. Yanlış çalışıyor. Bu da bir tür doğruluktur.

**Neden Türkçe?**  
Çünkü 404 Türkçe de 404’tür.

**Siyasi mi?**  
Hayır. Kesinlikle hayır. Hiçbir şey gizli değil. Kodda gördüğünüz base64 de sadece estetik.
